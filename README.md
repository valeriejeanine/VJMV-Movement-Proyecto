# VJMV MOVEMENT — BUILT TO MOVE

Proyecto final integrador de **Desarrollo de Software IV** (Backend API REST en C# con SQL Server) y **Desarrollo de Software V** (Frontend Web Responsivo).

---

## Información del Proyecto
- **Tienda:** VJMV Movement
- **Eslogan:** *"BUILT TO MOVE"*
- **Inspiración y Estilo:** Minimalista y atlético, inspirado en la tienda de indumentaria deportiva femenina **AYBL**.
- **Catálogo Femenino Base:**
  1. Leggings (*Balance V2 Seamless Leggings*)
  2. Tops Deportivos (*Empower Seamless Sports Bra*)
  3. Conjuntos Deportivos (*Balance V2 Seamless Set*)
  4. Mochila / Maletín Deportivo (*Everyday Matte Gym Bag*)
  5. Medias Deportivas (*Everyday Crew Socks Pack x3*)
  6. Shorts Deportivos (*Balance V2 Seamless Shorts*)

---

## Tecnologías Utilizadas
- **Backend:** C# / ASP.NET Core Web API (.NET 10)
- **Base de Datos:** SQL Server 2022 con Procedimientos Almacenados (Stored Procedures)
- **Frontend:** HTML5 semántico, CSS3 responsivo (Flexbox / CSS Grid), JavaScript ES6+ (Fetch API)
- **Control de Versiones:** Git y GitHub

---

## Estructura de la Solución
- `/database`: Script de base de datos (`VJMV_Movement_DB.sql`) con esquema, datos iniciales y procedimientos almacenados.
- `/backend`: API REST en C# con arquitectura en capas (Models, DTOs, Data, Services, Controllers).
- `/frontend`: Interfaz de usuario responsiva para la tienda y módulo administrativo de gestión.
- `/docs`: Documentación académica con normas APA 7 y evidencias de desarrollo.
